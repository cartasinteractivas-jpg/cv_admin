# WebPocket · cv_admin para GitHub Pages

Esta carpeta está lista para subirla completa al repositorio que servirá como sitio estático. El archivo `index.html` está en la raíz y los recursos compilados se encuentran en `assets/`.

## Publicación

Sube el contenido completo de esta carpeta a la rama que usarás para GitHub Pages. En **Settings → Pages**, selecciona la rama correspondiente y la carpeta **/(root)**. La aplicación usa rutas relativas, por lo que puede publicarse desde un repositorio de proyecto como `https://usuario.github.io/cv_admin/`.

Los videos de demostración se cargan desde los activos ya publicados de WebPocket. No subas claves de Supabase ni de OpenRouter a este repositorio.
