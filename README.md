# WebPocket · cv_admin para GitHub Pages

Sube el contenido completo de esta carpeta al repositorio. `index.html` y los ocho videos MP4 están en la raíz; los recursos compilados están en `assets/`.

La aplicación busca primero los videos locales `./video_*.mp4`. Si algún archivo aún no está disponible temporalmente, utiliza como respaldo la versión publicada en la rama `main` de `cartasinteractivas-jpg/cv_admin`.

En GitHub, abre **Settings → Pages**, selecciona la rama elegida y la carpeta **/(root)**. No subas claves de Supabase ni de OpenRouter.
